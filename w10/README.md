# Card Matching Game – Vibe Coding Project

## Description
This project is a card matching (memory) game built using a vibe coding tool. The purpose of the project is to explore how AI-powered development tools can assist in building a complete and functional game application.

## Features
- Card flipping interaction
- Matching logic for card pairs
- Move counter
- Game reset functionality
- Responsive layout

## Technologies Used
- HTML
- CSS
- JavaScript

## Vibe Coding Tool Used
- Replit Agent

## Installation and Setup
1. Clone the repository
2. Open the `index.html` file in your browser

## How to Run
Simply open `index.html` in any modern web browser.
